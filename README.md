## 📌 Project Overview
This project presents an interactive Coffee Shop Sales Dashboard designed to analyze sales performance, customer behavior, and operational trends across multiple store locations. The dashboard provides clear, actionable insights through KPIs and visualizations to support data-driven decision-making.

## 🎯 Objectives
- Track overall sales and customer footfall
- Understand purchasing patterns by time, day, and month
- Analyze product category and size preferences
- Compare performance across store locations

## 📊 Key Metrics
- Total Sales: $698,812.33
- Total Footfall: 149,116
- Average Bill per Person: 4.69
- Average Orders per Person: 1.44

## 📈 Dashboard Insights
- Peak order volumes occur during morning hours
- Monthly sales show a steady upward trend from January to June
- Espresso and brewed beverages dominate category sales
- Regular and large sizes account for the majority of orders
- Sales vary across locations, with Astoria and Hell’s Kitchen leading

## 🛠 Tools & Technologies
- Power BI / Tableau (or Excel – adjust as applicable)
- Data Cleaning & Transformation
- Data Visualization & KPI Analysis

## 📂 Dataset
- Transaction-level coffee shop sales data including date, time, product category, size, location, and bill amount
